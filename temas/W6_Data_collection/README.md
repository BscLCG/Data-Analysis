# Week 6: Sample, Data Collection, and Instruments

## Overview

This week covers the fundamental aspects of data collection for quantitative research, emphasizing survey design and sampling methodologies. It provides a practical guide to building surveys using the Qualtrics environment, as well as the theoretical foundations required to select samples, estimate statistical power, and ensure the reliability and validity of measurement instruments.

## Key Concepts

- **Survey Design in Qualtrics:** Organizing questionnaires using blocks, applying randomization, configuring logic (branches and skip logic), and creating embedded data to store experimental conditions.
- **Sampling Process:**
  - *Target Population:* The complete set of elements of interest.
  - *Sampling Frame:* The available pool of potential respondents.
  - *Types of Samples:* Probability panels, commercial marketplaces (e.g., MTurk, Prolific), and convenience samples.
- **Errors in Survey Research:**
  - *Coverage Error:* When the sampling frame fails to cover the entire target population.
  - *Sampling Error:* Uncertainty generated by relying on a random sample rather than the entire population.
  - *Non-response and Attrition:* Bias introduced when specific groups systematically drop out or fail to participate.
- **Hypothesis Testing and Uncertainty:**
  - *P-Value:* The probability of obtaining a sample result as extreme as the one observed if the null hypothesis ($H_0$) is true.
  - *Type I Error ($\alpha$):* False positive (rejecting $H_0$ when it is true).
  - *Type II Error ($\beta$):* False negative (failing to reject $H_0$ when it is false).
- **Statistical Power Analysis:** Calculating the required sample size based on the significance level, test power ($1 - \beta$), and the Minimum Detectable Effect (MDE).
- **Instrument Quality:**
  - *Reliability:* Consistency in how all respondents interpret and answer a question.
  - *Validity:* The correspondence between the response and the true construct the researcher intends to measure.

## Relevant Points

- **Measurement, not Conversation:** Survey questions are measurement tools and must be explicitly defined so they mean the exact same thing to all respondents. Ambiguity reduces reliability.
- **Power Calculations:** Determining sample size must be done *a priori* (during planning) based on expected effect sizes and desired statistical power, not post hoc.
- **Qualtrics Best Practices:** Using "Randomizer" blocks and "Embedded Data" ensures that experimental conditions are correctly assigned and recorded for later analysis in software like R or Stata.
